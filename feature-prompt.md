
##event registration
Read AGENTS.md first

Add event registration to the Event Organizee app. Attendees can register for an event and cancel their registration. Each event shows how many spots are left and shows “Full” when no spots remain. A “My Events” page lists the events the user has registered for. Organizers can see who has registered for each event.

Registration rules:
* Users can register for an event only once.
* Registration is closed once the event has ended.
* Cancelling frees the spot straight away.
